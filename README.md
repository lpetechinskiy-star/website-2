# ЧУГУН — сайт стейк-хауса

Одностраничный сайт премиального стейк-хауса на Патриарших. Статика без сборки:
открывается двойным кликом, деплоится на любой хостинг копированием папки.

**Стек:** HTML + собственный CSS с дизайн-токенами + GSAP/ScrollTrigger.
**Сторонних запросов — ноль.** Шрифты, скрипты и графика лежат рядом с сайтом.

```
index.html                 вся разметка
assets/css/styles.css      дизайн-система и компоненты
assets/css/fonts.css       @font-face для локальных шрифтов
assets/js/main.js          поведение
assets/js/vendor/          GSAP 3.12.5 + ScrollTrigger
assets/fonts/              Oswald, Inter, Playfair Display (subset)
assets/img/                графика секций, зерно плёнки, favicon
tools/subset-fonts.py      пересборка шрифтов под используемые глифы
design-system/chugun/      дизайн-система: токены и правила
```

## Запуск

```bash
python3 -m http.server 8000     # затем http://localhost:8000
```

Открывать по HTTP, а не через `file://`: браузер не отдаёт локальные шрифты
по file-протоколу (CORS), и текст отрисуется системным шрифтом.

## Деплой

Залить содержимое папки в корень хостинга. Ничего собирать не нужно.
Включите на сервере **gzip или brotli** — текстовые файлы сжимаются примерно
на 70 %, это главный оставшийся выигрыш в скорости.

Первая загрузка сейчас: **≈424 КБ без сжатия, 21 запрос, 0 сторонних**,
FCP/LCP ≈ 370 мс, CLS = 0 на локальном сервере.

## Что нужно заменить перед продакшеном

### 1. Фотографии

Сейчас в `assets/img/` лежат **не фотографии, а сгенерированные SVG-пластины** —
атмосферные слои света, углей и дыма. Они держат тон, пока нет съёмки, весят
по 5–30 КБ и масштабируются без потерь. Это осознанная замена: рисовать
поддельную еду вектором на премиум-сайте нельзя, а пустые серые плейсхолдеры
убили бы впечатление.

Чтобы поставить настоящие кадры — положите файл рядом и поменяйте путь
в `index.html`. Размеры в `width`/`height` уже проставлены, поэтому вёрстка
не дёрнется (CLS остаётся 0) — важно сохранить **пропорции**:

| Файл | Пропорции | Что снимать |
|---|---|---|
| `hero-grill` | 16:9, от 1920px | Угли под решёткой, тёмный кадр, свет снизу |
| `dish-tbone` · `dish-tomahawk` · `dish-ribeye` · `dish-striploin` | 4:5 | Отруб на чугуне, контровой свет, много тени |
| `story-fire` | 3:4 | Повар у огня, силуэт против пламени |
| `gallery-01…06` | 3:2, два кадра 4:5 | Зал, бар, дым, подача, детали |
| `wine-cellar` · `bar-counter` | 4:3 | Погреб и барная стойка |
| `event-cabinet` · `event-cellar` · `event-hall` | 3:2 | Площадки под события |
| `place-facade` | 16:9 | Фасад вечером |
| `og-cover` | 1200×630 | Картинка для соцсетей |

Снимать тёмно и контрастно: сайт построен на одном тёплом источнике света.
Готовить в WebP/AVIF, длинная сторона 1600–2000 px, до 200 КБ на кадр.

После замены текстов и фото прогоните `python3 tools/subset-fonts.py`,
если появились символы вне русского и английского.

### 2. Приём броней

Кнопка «Забронировать» в любом месте страницы открывает модальное окно
в два шага: сначала дата, время, гости и зал, затем контакты.

Форма сейчас работает в демо-режиме: данные уходят в консоль, гостю
показывается экран подтверждения. Чтобы включить реальную отправку — укажите
адрес своего обработчика в `index.html`:

```html
<form class="form" id="res-form" data-endpoint="https://api.example.com/booking">
```

Форма отправит `POST` с JSON: `name, tel, date, time, guests, zone, occasion, note, consent`.
Ожидается ответ `2xx`; на любой другой гость увидит сообщение об ошибке
и телефон ресторана.

**Часы посадки** заданы в `assets/js/main.js` — там же, где остальная логика
бронирования:

```js
const FIRST_SLOT = 12;                            // первая посадка
const LAST_SLOT  = [21, 22, 22, 22, 22, 23, 23];  // вс, пн, вт, ср, чт, пт, сб
const LEAD_MIN   = 60;                            // бронь минимум за час
```

Эти же цифры должны совпадать с расписанием в секции «Как найти» и в блоке
`application/ld+json` — они не связаны автоматически. Горизонт брони —
60 дней, задаётся в той же функции (`addDays(TODAY, 60)`).

Календарь сам отключает прошедшие дни, а на сегодня — уже прошедшие слоты
(по московскому времени, а не по часам гостя).

Дата, время, гости, зал и повод выбираются своими виджетами: ни один системный
выпадающий список в окне не открывается. Список поводов задаётся опциями
`<select id="f-occ">`, а иконки к ним — в `OCC_ICONS` в `assets/js/main.js`
(ключ совпадает со значением опции; если иконки нет, плашка просто без неё).

**Без JavaScript** модальное окно не открывается, поэтому форма остаётся прямо
в секции «Бронирование» и работает на нативных полях: `<input type="date">`,
списки времени и гостей. Проверку в этом случае делает браузер. Если хотите,
чтобы такая отправка тоже доходила до вас, добавьте форме обычный
`action="/booking"` и `method="post"` — иначе гостю без скриптов остаётся
телефон, который указан рядом с кнопкой.

### 3. Реквизиты

Название, адрес, телефоны, почта, цены, имена шефа и сомелье — вымышленные.
Заменяются в `index.html`; телефон встречается в шапке, мобильном меню,
секции событий, форме, подвале и в блоке `application/ld+json` для поисковиков.

## Доступность

Проверено в сборке:

- контраст всего текста ≥ 4.5:1 на обеих поверхностях (замерено, не на глаз);
- клавиатура: табы меню на стрелках, лайтбокс на стрелках и Esc, видимый фокус;
- ошибки формы — под полем, связаны через `aria-describedby`, плюс сводка
  сверху с фокусом и ссылками на поля;
- `prefers-reduced-motion`: анимации выключаются, бегущая строка встаёт,
  контент сразу в финальном состоянии;
- без JavaScript страница читается целиком — ничего не спрятано за скриптом;
- липкая кнопка на мобильном уходит, когда гость ставит фокус в поле,
  чтобы не перекрывать его.

## Карта

Карта Яндекса грузится **только по клику** — до этого страница не отправляет
ни одного запроса на сторонние серверы.
