# ЧУГУН — дизайн-система

Источник правды для сайта. Правила ниже уже реализованы в
`assets/css/styles.css`; токены меняются в блоке `:root`.

## Направление

**Dark editorial / exaggerated minimalism.** Почти чёрная основа, один тёплый
источник света, латунь и угли как единственные цветовые события. Крупная
узкая типографика работает как главный носитель характера — не декор.

Отвергнуто осознанно:

- **Liquid Glass** — его предлагает поиск по ключевым словам «premium/luxury»,
  но это язык системного хрома Apple, а не мяса и огня.
- **Фотореалистичная еда вектором** — проверено на макетах, стейк читается
  как булка. Лучше честная фактура угля под крупным шрифтом.
- **Предметные силуэты** (столы, стулья, окна) — на тёмном фоне выглядят
  игрушечно. Работает только свет: угли, дым, контровой силуэт, боке.

## Цвет

Семантические токены, не сырые hex в компонентах.

| Токен | Значение | Роль |
|---|---|---|
| `--ink` | `#0C0A09` | основная подложка |
| `--coal` | `#16130F` | чередующиеся секции, подвал |
| `--smoke` | `#241F1A` | приподнятые поверхности |
| `--ash` | `#3A332C` | границы полей, рамки |
| `--bone` | `#F5F1EA` | основной текст — 17.5:1 / 15.7:1 |
| `--mute` | `#A8A29E` | вторичный текст — 7.8:1 / 7.1:1 |
| `--faint` | `#8B847C` | подписи и хинты — 5.4:1 / 5.0:1 |
| `--brass` | `#D4A03C` | акцент, CTA, цены — 8.4:1 |
| `--ember` | `#E0552B` | огонь, только в графике и градиенте заголовка |
| `--danger` | `#FF6B5A` | ошибки формы — 6.1:1 |

Контраст указан на `--ink` и на `--coal`. **Любой новый цвет текста должен
проходить 4.5:1 на обеих поверхностях**, иначе он сломается в чередующихся
секциях — именно так `--faint` пришлось поднять с `#7A736C`.

Акцент — только один на экран. Красный `--ember` не используется для текста.

## Типографика

| Роль | Шрифт | Применение |
|---|---|---|
| Дисплей | **Oswald** 500–700 | заголовки, кнопки, лейблы, цифры, навигация |
| Текст | **Inter** 400–600 | абзацы, поля, подписи |
| Цитата | **Playfair Display Italic** | только пул-квоты, больше нигде |

- Заголовок первого экрана: `clamp(2.9rem, min(13.5vw, 13.5svh), 9rem)` —
  ограничение по **высоте** обязательно, иначе CTA уходит под фолд
  на ноутбуке 1440×900.
- Базовый кегль 16 px, интерлиньяж 1.65, строка 52–62 знака.
- Лейблы и китикеры: Oswald, uppercase, трекинг `.14–.26em`.
- Цены, вес, даты, часы — `.tnum` (`font-variant-numeric: tabular-nums`),
  чтобы колонки не дёргались.
- Заголовки — `text-wrap: balance`, абзацы — `text-wrap: pretty`.

## Ритм и сетка

- Шаг 4 pt: `--s1…--s10` (4 → 128 px).
- Контейнер `--wrap: 78rem`, поля `clamp(1rem, 4vw, 3.5rem)`.
- Брейкпоинты: **640 / 900 / 1150**. Mobile-first, дальше вверх.
- Углы `--r: 0` — резкие, как того требует урбан-язык. Скруглений нет нигде.
- Слои: `0 / 10 / 40 / 100 / 1000` (`--z-*`), без произвольных `z-index`.

## Движение

Токены `--d-fast 160ms`, `--d-base 280ms`, `--d-slow 520ms`,
`--e-out cubic-bezier(.16,1,.3,1)`.

- Анимируются только `transform` и `opacity` — никогда `width/height/top`.
- Появление секций: сдвиг 22 px + прозрачность, `power3.out`, один раз.
- Сетки выходят волной: `stagger .07`, не все разом.
- Заголовок первого экрана: три строки выезжают из своего `overflow`, `expo.out`.
- Параллакс героя — `scrub`, только `yPercent`.
- **`prefers-reduced-motion` выключает всё**, контент сразу в финальном
  состоянии, бегущая строка останавливается.

## Обязательное

- Иконки — инлайн-SVG со `stroke-width` 1.6–1.8. Эмодзи вместо иконок запрещены.
- Декоративные иконки — `aria-hidden="true"`; иконка-кнопка получает имя
  через `.vh`-текст.
- Всякий `<img>` несёт `width`/`height` — CLS держим на нуле.
- Всё, что грузится не сразу, — `loading="lazy"`; первый экран — `fetchpriority="high"`.
- Фокус виден всегда: `2px solid var(--brass)`, отступ 3 px. Снимать нельзя.
- Цвет никогда не единственный носитель смысла: у ошибок есть значок и текст.
- Ничего не прячется за JavaScript. Разметка полная, скрипт только оживляет.
- `[hidden] { display: none !important }` — иначе `display: grid` компонента
  перебивает атрибут и скрытые панели показываются (эта ошибка уже ловилась).
